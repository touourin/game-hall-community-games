# 原创模型资产

- `share-card-sheet.svg`：四种份额卡正面、统一牌背和抵押状态的语义模型板。
- `table-scene-blueprint.svg`：桌面端牌桌区域、三条航线、港口/船坞、特殊岛和私密区的布局蓝图。

两张 SVG 都由 `../scripts/generate_assets.py` 根据 `../model/card-model.json` 与 `../model/component-catalog.json` 确定性生成，带有 `data-model-version="1.0.0"`。修改源模型后应重新运行生成器，不直接编辑生成物。

这些文件是产品与工程沟通用的原创中性蓝图，不是官方版图复刻，也不是可打印替代套件。不得向其中粘贴官方 Logo、规则书截图、卡面插画、包装或版图扫描。
