# 《算途疾行》玩家模型

> 第三人称完整角色、双帧奔跑、转弯、跳跃与低姿滑行 v3.0

## 1. 角色定位

“逐光者”是第三人称桥面跑者。原创身份与服装参考位于 `images/runner-character-concept.png`；运行时动作图集位于 `frontend/assets/runner-motion-atlas.png`。图集保持同一名年轻跑者、黑色乱发、炭灰短夹克、橙色滚边、象牙色内层、深色长裤和青色腕表，避免旧版几何小人造成的简陋感。

## 2. 动作图集

图集为 `1536 × 1024` 透明 PNG，严格划分为六个 `512 × 512` 单元：

| 单元 | 姿态 | 运行时职责 |
| --- | --- | --- |
| 左上 | 向前跑 A | 左腿/右臂推进 |
| 中上 | 向前跑 B | 右腿/左臂推进 |
| 右上 | 右转 | 躯干、髋部和落脚方向向右倾入弯道 |
| 左下 | 左转 | 躯干、髋部和落脚方向向左倾入弯道 |
| 中下 | 跳跃 | 腾空并收起双腿 |
| 右下 | 低姿滑行 | 身体压低、一腿伸展、一腿收起 |

运行时只显示一个完整人物轮廓，不再拼接头、躯干和胶囊形四肢。模型根节点位于画面下方桥面接触点，逻辑宽度按场景在 154–218 px 间响应式变化。

## 3. 奔跑循环

- 周期随等级从 720 ms 缩短到 430 ms。
- A/B 两个完整步态以离散帧交替，腿、髋、肩和手臂同时改变，而不是整张图只上下抖动。
- 人物只保留约 2 px 的轻微重心起伏；脚下接触影和两条短速度尾迹与步频同步。
- 桥面枕木、护栏路标、透视网格和速度线持续向镜头移动，与步态共同表达人物真实向前跑。

## 4. 四个操作姿态

### `left` / `right`

- 立即切换为对应方向的完整转弯姿势。
- 人物根节点沿目标跑道横移，镜头和桥面向反方向轻转。
- 身体、髋部、手臂和落脚方向全部进入弯道，而不是只将直立人物旋转。
- 620 ms 后回到双帧奔跑。

### `jump`

- 16% 时间内起跳，52%–62% 位于最高点。
- 根节点上移约 82 px，显示专用收腿腾空姿势。
- 接触影缩小并变淡，末段落回桥面后恢复跑步。

### `slide`

- 显示专用低姿滑行动作，人物轮廓上提并适度放大，确保在深色桥面上仍清楚可见。
- 身体保持在高空横梁下方，一腿伸展、一腿收起。
- 桥面产生轻微反向镜头位移，620 ms 后恢复跑步。

## 5. 结束姿态

- `wrong`：保留倾弯姿态并失衡刹停，不表现坠落或受伤。
- `timeout`：使用低姿制动姿态，在障碍前停止。
- `completed`：保留奔跑帧并向消失点缩小。

## 6. 服务端映射

```text
playing + 未提交          -> run-a <-> run-b
新快照 lastAction=left   -> left -> run-loop
新快照 lastAction=right  -> right -> run-loop
新快照 lastAction=jump   -> jump -> run-loop
新快照 lastAction=slide  -> slide -> run-loop
finished/wrong           -> left-pose + stumble
finished/timeout         -> slide-pose + brake
finished/completed       -> run-frame + finish
```

客户端提交后可以锁住重复输入，但只有服务端推进题目并返回 `lastAction` 后才播放成功动作。

## 7. 减弱动态

`prefers-reduced-motion: reduce` 时停止双帧循环、桥面流动和速度尾迹：

- 保留一张静态跑步帧。
- 左右、跳跃和低姿滑行使用对应完整姿态与较小静态位移。
- 规则、倒计时和服务端判定不变。

## 8. 验收标准

1. 未操作时两个完整奔跑姿态确实交替，腿部位置清楚变化。
2. 桥面枕木和双侧路标持续向镜头移动，不依赖人物原地抖动表达速度。
3. W 动画能看到完整腾空与收腿。
4. S 动画能看到明显压低与滑行。
5. A/D 动画能看到专用转弯姿势、横移和镜头转向。
6. 四个成功动作只在服务端确认后播放。
