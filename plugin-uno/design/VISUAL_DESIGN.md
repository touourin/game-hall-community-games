# 视觉设计方案：Prism Arena

## 1. 设计目标

玩法本身非常易懂，因此画面不靠堆叠信息制造“复杂感”，而是把简单动作做得有重量：卡牌像带有微蚀刻纹理的收藏级实体，桌面像一座会响应颜色与方向的装置，功能牌则像短促但清晰的技能释放。

视觉关键词：`黑曜石 / 烟熏玻璃 / 棱镜 / 精密金属 / 克制光晕 / 清晰节奏`。

不采用：官方 UNO 红色椭圆 Logo、官方卡背、赌场筹码、扑克牌花色、廉价霓虹边框或持续遮挡牌面的粒子雨。

## 2. 色彩系统

| 用途 | ID | 主色 | 深色 | 说明 |
| --- | --- | --- | --- | --- |
| 赤红 | `red` | `#FF4D62` | `#8F152B` | 强动作、跳过、抓漏喊 |
| 琥珀 | `yellow` | `#FFC83D` | `#A45E05` | 奖励、摸牌与 `+2` |
| 翠绿 | `green` | `#35D78B` | `#087449` | 平衡、恢复牌桌节奏 |
| 湛蓝 | `blue` | `#438FFF` | `#1644A0` | 默认交互、反转与选中态 |
| 黑曜石 | `ink` | `#070910` | `#03050A` | 场景与卡牌外壳 |
| 冷白 | `text` | `#F5F8FF` | — | 核心信息 |

四种游戏色只承担规则识别，场景大面积仍由黑、灰、烟熏玻璃组成，防止长时间游戏造成视觉疲劳。

## 3. 卡牌结构

运行时卡面由 `frontend/components/PrismCard.vue` 绘制，保持矢量级清晰度。

从外到内共六层：

1. 黑曜石外壳与接触阴影；
2. 细白金属描边；
3. 颜色材质层与暗部渐变；
4. 倾斜 17° 的玻璃椭圆；
5. 中央数字或功能图形；
6. 受控高光扫过层。

卡牌宽高比固定为 `2:3`，圆角约为短边的 `13.5%`。数字使用重字重圆角无衬线体，角标与中心信息保持同源。选中牌上移约 15px，并只在可出牌周围添加弱光，不用持续弹跳。

### 功能图形

- 跳过：完整圆环与 45° 切线，动画中转化为横向时间切片。
- 反转：两条首尾相接的轨道箭头，动画方向跟随服务端 `direction`。
- `+2`：加号较小、数字为主，强调惩罚数量。
- 万能：四色晶片围绕中央空隙构成棱镜。
- 万能 `+4`：在万能图形中心嵌入高对比 `+4`，并调用透明奇点素材。

### 牌背

`prism-card-back.png` 采用对称的黑色精密结构与四条能量轨迹。它不包含任何文字或官方标志，缩小后仍能通过中央四色晶体辨认。

## 4. 场景结构

`prism-arena.png` 是稍俯视 3/4 镜头，中央留有大面积纯净桌面。前端再叠加四层实时 UI：

1. 场景图与暗角；
2. 行动方向轨道；
3. 牌库、弃牌堆和当前颜色光谱；
4. 玩家信息、手牌和动作面板。

出现 `+2 / +4` 惩罚链时，桌芯下缘点亮一枚琥珀色“惩罚反应堆”，持续显示累计 `+N` 与被锁定玩家。它复用黑曜石、烟熏玻璃和精密金属语言，不新增另一套面板风格；只有惩罚待结算时出现，清零后立即收起。

当前颜色只改变桌沿弱光和弃牌堆光晕，不对整张场景重新染色。这样红、黄、绿、蓝卡牌在任何状态下都能保持可读。

## 5. 信息层级

- 第一层：自己的手牌、顶牌、当前颜色、是否轮到自己。
- 第二层：其他玩家张数、方向、惩罚链总数与锁定玩家。
- 第三层：历史记录、快速规则、牌堆数量。
- 演出层：只在功能牌生效后的 1.0–1.55 秒出现，始终 `pointer-events: none`。

## 6. 响应式布局

- 默认画布占满宿主提供的内容宽度，并至少覆盖一个动态视口高度；大厅的退出、房间与系统按钮保留在插件外层。
- 插件内全屏按钮可让牌桌铺满 `100vw × 100vh`，全屏时移除外层圆角并允许纵向滚动，避免矮屏裁掉手牌或操作栏。
- `> 960px`：三段 HUD、椭圆牌桌、手牌与操作栏同排。
- `681–960px`：HUD 两列，操作栏移动到手牌下方。
- `391–680px`：对手席横向滚动，手牌横向滑动，牌桌缩窄。
- `≤ 390px`：隐藏辅助英文标签，保留规则所需数字、颜色、累计 `+N` 与动作。

不允许页面级横向滚动；只有对手席与手牌本身可以横向滚动。

## 7. 无障碍

- 每张牌的按钮标签使用完整中文牌名，不只依赖颜色。
- 颜色选择器同时显示色块与中文名称。
- 当前行动、UNO 警戒和选中态都有非颜色提示。
- 所有演出均提供文本状态，并响应 `prefers-reduced-motion`。
- 减少动态模式隐藏高速线、旋转环和粒子图，只保留 700ms 淡入淡出。
- 键盘焦点使用 2px 高对比白色描边。

## 8. 性能预算

正式发布建议：

- 场景图：WebP/AVIF，目标不超过 500KB。
- 牌背：WebP，目标不超过 180KB。
- 透明效果：压缩 PNG/WebP，目标不超过 450KB。
- 同时播放的 CSS 动画层不超过 24 个；主要只动画 `transform / opacity`。
- 低端移动设备禁用背景模糊时，界面仍需保持层级清晰。

当前目录保留高质量 PNG 母版，便于继续调色与审核；发布前再生成运行时压缩版本。
