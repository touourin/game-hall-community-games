# 《骷髅牌》规则说明书

> Skull 简体中文数字化建模版 v1.0
>
> 适用人数：3-6 人｜建议年龄：10+｜参考时长：约 30 分钟｜类型： bluff / 竞标 / 心理博弈

本说明书依据当前 Space Cowboys 英文规则重新整理，以原创中文表述服务于软件实现和试玩。它不是官方中文规则书，不包含官方美术。实体版常把圆形组件称为 disc；本说明书统一称为“牌”或“圆牌”，并把 Flower 译作“花牌（玫瑰）”。

## 1. 一分钟理解游戏

每位玩家拥有 3 枚花牌和 1 枚骷髅牌。大家把牌面朝下叠在自己面前，既可以继续叠牌，也可以宣布自己敢翻开多少枚牌而不碰到骷髅。叫价最高者成为挑战者，必须先从自己的牌堆翻起，再从其他玩家的牌堆中挑选。

- 成功翻满叫价数量且全是花：赢得 1 次挑战。
- 翻到任意骷髅：挑战失败，并永久失去自己的 1 枚牌。
- 率先赢得 2 次挑战者获胜；若其他人全部被淘汰，最后留下的玩家也获胜。

这不是一道纯概率题。你知道自己放了什么，却不知道别人是在保护你、诱导你，还是等你亲手翻开陷阱。

## 2. 游戏组件

标准 3-6 人游戏需要：

| 组件 | 数量 | 说明 |
| --- | ---: | --- |
| 玩家垫 | 6 | 每位玩家 1 张；空白面表示 0 次成功，花面表示已成功 1 次 |
| 个人圆牌 | 24 | 6 套，每套 4 枚：3 花、1 骷髅；同一套牌背相同 |
| 最后机会牌 | 1 | 新版可选规则使用；所有人都知道它是一枚花牌 |
| 规则说明 | 1 | 本文件可作为数字化试玩规则 |

如果只进行经典模式，不使用最后机会牌。

## 3. 游戏目标

以下任一条件达成时，游戏立即结束：

1. 一名玩家作为挑战者第二次成功，立即获胜。
2. 除一名玩家外，其他玩家都已失去最后一枚个人牌并被淘汰；剩余玩家获胜。

一次成功不会因为以后失牌而取消。被淘汰玩家即使已经成功过一次，也不能继续游戏。

## 4. 游戏准备

1. 每位玩家选择一套牌，拿取同色玩家垫、3 枚花牌和 1 枚骷髅牌。
2. 玩家垫空白面朝上放在自己面前，四枚个人牌拿在手中，牌面不向他人展示。
3. 选择首家。实体版可采用“最近送过花或骷髅的人”，数字版建议由房间设置决定随机首家或房主首家。
4. 若启用最后机会规则，把唯一的最后机会牌放到公共供应区。

玩家可以自由交谈、误导、说真话或虚张声势，但不得偷看别人的暗牌，也不得展示受规则要求保持秘密的弃牌。

## 5. 一轮游戏

每轮依次经过：

`秘密准备 -> 叠牌或开叫 -> 加价或暂不跟价 -> 挑战翻牌 -> 成功或处罚 -> 确定下一轮首家`

### 5.1 秘密准备

每名仍在场的玩家从手中选择 1 枚牌，面朝下放在自己的玩家垫上。

- 所有人都必须放 1 枚，不能跳过。
- 首家应等待其他玩家完成选择后，再完成自己的选择。
- 数字版应同时锁定选择，避免首家利用提交先后读取信息。
- 已经失去部分牌的玩家只从自己剩余的牌中选择。

所有人完成后，进入公开轮流行动。

### 5.2 叠牌或开叫

从首家开始顺时针行动。轮到你时，只能选择一项：

1. **叠放一枚牌**：从手中选 1 枚，面朝下放到自己现有牌堆的最上方；牌之间应略微错开，让所有人看得出数量。
2. **开启竞标**：宣布一个正整数，表示你愿意尝试翻开的牌数。

首家在本阶段第一次行动时就可以直接开叫，不必先叠第二枚牌。若你手中已经没有可叠的牌，则必须开叫。

开叫数字必须满足：

- 至少为 1；
- 不超过桌面所有玩家垫上暗牌的总数。

一旦任何人开叫，本轮禁止继续叠牌，立即进入竞标。

### 5.3 加价或暂不跟价

开叫后仍按顺时针行动。轮到你时，只能：

- **加价**：报出一个比当前叫价更大的数字，且仍不得超过桌面暗牌总数；可以一次提高多个数字。
- **暂不跟价**：不提高当前最高叫价。这只对当前这一口叫价有效；只要任意玩家随后加价，所有此前暂不跟价的玩家都会恢复行动资格，并可在再次轮到自己时继续加价。你放在玩家垫上的暗牌始终留在桌面，仍可能被最终挑战者翻开。

每次出现新最高叫价后，从其下一家开始，其他所有仍在场的玩家都必须重新回应。只有当他们全部选择暂不跟进这一个最新叫价时，最高叫价者才成为本轮挑战者，其叫价成为目标数量。若叫价已经等于桌面暗牌总数，因为无人还能合法加价，可立即进入挑战。

## 6. 挑战与翻牌

挑战者必须逐枚翻牌，直到成功翻满叫价数量，或翻到骷髅立即失败。

翻牌必须遵守以下顺序：

1. 每次只翻 1 枚。
2. 必须先从挑战者自己的牌堆开始。
3. 每个牌堆只能翻当前最上方仍面朝下的牌，不能越过上层牌去翻下面的牌。
4. 只有在需要继续翻牌、且挑战者自己的所有暗牌都已翻开后，才可以翻其他玩家的牌。
5. 进入其他玩家区域后，挑战者可以在不同玩家牌堆之间自由切换，但每次仍只能翻各牌堆顶部的暗牌。
6. 若叫价等于桌面总牌数，挑战者必须把桌面所有牌都翻开。

如果挑战者只靠自己的牌堆就已达到叫价，立即停止，不需要把自己的剩余暗牌翻开。未被规则翻开的牌继续保密。

### 6.1 挑战成功

当挑战者翻开的牌数等于叫价，并且全部为花牌时，本轮成功：

- 第一次成功：把自己的玩家垫翻到花面，表示已有 1 次成功。
- 第二次成功：立即赢得整局游戏。

### 6.2 挑战失败

一旦翻到骷髅：

1. 立即停止，不能再翻任何牌。
2. 挑战者永久失去自己的一枚个人牌。
3. 处罚完成前，不公开未翻开的牌；其他玩家可以在实体桌上自愿亮牌证明自己是否虚张声势，但这不改变结果。

失去哪一枚牌取决于骷髅属于谁。

#### 翻到他人的骷髅

挑战者把自己的全部剩余个人牌混在一起并保持牌面朝下。骷髅所有者在不知道牌面的情况下盲选 1 枚，放回盒中。

数字版应向选择者展示由服务端随机打乱的不透明槽位，而不是牌 ID、原位置或牌面。只有挑战者知道最终失去的是花还是骷髅。

#### 翻到自己的骷髅

挑战者查看自己的剩余个人牌，秘密选择 1 枚永久移除。其他玩家不知道被移除牌的种类。

#### 失去最后一枚个人牌

若处罚使挑战者不再拥有任何个人牌，该玩家立即被淘汰并移出后续回合。最后机会规则的特殊处罚见第 8 节。

## 7. 本轮结束与下一轮首家

结算成功或处罚后，所有未淘汰玩家收回自己仍保留的牌；玩家垫保持当前面朝上状态。下一轮重新从秘密准备开始。

下一轮首家按以下优先级确定：

| 情况 | 下一轮首家 |
| --- | --- |
| 挑战者没有被淘汰 | 原挑战者，无论本轮成功或失败 |
| 挑战者被他人的骷髅淘汰 | 被翻到骷髅的所有者 |
| 挑战者被自己的骷髅淘汰 | 被淘汰的挑战者指定一名仍在场玩家 |

如果结算后只剩一名玩家，先判定整局结束，不再创建下一轮。

## 8. 新版可选规则：最后机会牌

开启 `lastChanceEnabled` 后，使用唯一的公共最后机会牌。

### 8.1 获得条件

当一名挑战者失败并失去一枚牌，而处罚后恰好只剩 1 枚个人牌时：

- 若该玩家本局从未获得过最后机会牌，则拿取它；
- 它只能在紧接着的下一轮使用；
- 所有人始终知道它是一枚花牌；
- 每名玩家整局最多获得一次。

### 8.2 使用期限

最后机会牌与普通牌一样，可以在秘密准备或后续叠牌行动中面朝下放置，并计入桌面总牌数与叫价上限。因为它外观独立，所有人知道该位置是一枚安全花牌。

无论持有者是否打出，下一轮结束时都要把它归还公共供应区。它不能被保留到更晚回合。

### 8.3 特殊失败

在最后机会生效的那一轮，如果持有者成为挑战者并失败，则同时失去：

- 最后机会牌；
- 自己仅剩的最后一枚个人牌。

该玩家立即被淘汰，不再进行普通的随机弃牌选择。最后机会牌随后回到供应区。

若持有者没有成为失败的挑战者，则其个人牌不受这条特殊规则影响；回合结束时只归还最后机会牌。

## 9. 完整示例

阿岚、白露和赤岩进行三人游戏，本轮共有 5 枚暗牌：

- 阿岚面前 2 枚；
- 白露面前 2 枚；
- 赤岩面前 1 枚。

赤岩开叫 2。阿岚加到 3，白露暂不跟价，赤岩加到 4。由于出现了新叫价，白露恢复行动资格；阿岚暂不跟进 4，白露再次暂不跟进 4。此时其余玩家都已拒绝最新叫价，赤岩成为挑战者，目标为 4。

赤岩必须先翻自己的唯一一枚牌，结果是花。还差 3 枚，他选择白露的牌堆，先翻顶部，仍是花；然后转去阿岚处翻顶部，也是花。最后他再次选择白露，只能翻白露牌堆此时新的顶部牌。如果它是花，赤岩成功；如果是骷髅，赤岩立即失败，由白露从赤岩的 4 枚个人牌中盲选 1 枚永久移除。

即使阿岚牌堆底部也是花，赤岩也不能越过阿岚尚未翻开的顶部牌直接选择它。

## 10. 常见问题

### 开叫者一定会成为挑战者吗？

不一定。其他玩家可以加价，最终只剩的最高叫价者才是挑战者。

### 暂不跟价后，还能重新加价吗？暗牌还会被翻吗？

能。暂不跟价只拒绝当时的最高叫价；若之后有人提高叫价，你会重新进入行动顺序。无论是否暂不跟价，你的牌堆都不会撤走，仍可能被挑战者翻开。

### 可以只翻别人的牌，不翻自己的牌吗？

不可以。挑战者必须从自己的牌堆开始；只有在仍未达到叫价且自己的暗牌已经处理完后，才能转向别人。

### 翻别人两层牌时，可以先翻底牌吗？

不可以。每个牌堆都只能从当前最上方的暗牌开始。

### 失败后，大家会知道挑战者失去了什么吗？

不会。无论是对手盲选还是挑战者秘密自选，牌面都只让挑战者知道。

### 一名玩家只剩一枚牌时还能继续吗？

可以。每轮仍需放置自己的牌；之后手中没有牌可叠，因此轮到该玩家时必须开叫。若启用最后机会规则且满足获得条件，可在下一轮临时多使用一枚公开花牌。

### 可以谎称自己放了骷髅吗？

可以。桌面谈话与心理影响是玩法的一部分，规则不会验证玩家的口头陈述。

### 三人局是否有特殊胜利条件？

没有。仍然是成功两次或成为最后存活者；但人数少时信息更集中、失误更致命。

## 11. 数字版裁定摘要

| 裁定点 | 服务端要求 |
| --- | --- |
| 初始暗置 | 同时提交并锁定，所有有效玩家完成后再公开数量 |
| 叠牌 | 只能使用自己手中仍存在的牌，放到自己牌堆顶部 |
| 叫价 | `1 <= 新叫价 <= 当前桌面牌数`，且加价严格大于当前值 |
| 暂不跟价 | 仅拒绝当前最高叫价；任意玩家加价后全部重置并重新获得回应机会 |
| 翻牌 | 每次只翻一个合法顶部；自己的牌堆优先 |
| 暗牌信息 | 只向所有者显示；翻开的牌才成为公共信息 |
| 对手处罚 | 服务端洗混后生成不透明槽位，由骷髅所有者盲选 |
| 秘密弃牌 | 牌面只写入挑战者私有视图 |
| 结束判定 | 每次成功、处罚或淘汰后立即检查 |
| 断线恢复 | 从服务端权威状态重建，不把客户端动画当作真值 |
