## 5. 本轮发现并修复的问题

1. 320 像素测试壳层曾固定 `min-width: 320px`，遇到占宽滚动条后产生 15 像素水平溢出；已改为流式宽度。
2. 移动端水晶球预览原为绝对定位，会盖住航道第三张牌；已改为独占网格行。
3. 移动端特性面板原按整张长牌桌垂直居中，首屏只能看到局部；已改为固定视口、内部滚动的强制选择面板。
4. 移动端终局面板原随长牌桌拉伸；已改为固定视口并在面板内滚动，保证计分与重开入口可达。
5. 首版宽屏把全部对手排在顶部，与四人场景模型的环桌座位不一致；已改为西／北／东三向座位，中小屏仍按模型折叠。

修复后重新截图并复跑边界测量、类型检查与组件测试。
