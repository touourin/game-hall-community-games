# 《算途疾行》玩家模型

> 角色几何、跑步循环、变道、跳跃与下蹲姿态 v2.0

## 1. 角色定位

“逐光者”是第三人称桥面跑者。原创造型参考位于 `images/runner-character-concept.png`；运行时使用 DOM/CSS 几何重建，保证每个肢体可独立动画。

## 2. 几何分层

| 分层 | 运行时形状 | 动画职责 |
| --- | --- | --- |
| 头部与头发 | 圆角椭圆 + 多片短发 | 跑动微沉、变道先导 |
| 躯干与夹克 | 收腰圆角梯形 | 呼吸、倾斜、下蹲压低 |
| 左/右臂 | 独立胶囊体 | 与对侧腿反相摆动 |
| 左/右腿 | 独立胶囊体 | 跑步、跳跃收腿、滑行展开 |
| 鞋 | 扁圆楔形 | 落脚、蹬地和滑行方向 |
| 接触影 | 扁椭圆 | 表达落脚、腾空和速度 |

角色逻辑尺寸为 58×112。根节点位于双脚中点，所有肢体围绕各自锚点旋转。

## 3. 跑步循环

- 周期随等级从 720 ms 缩短到 430 ms。
- 左臂与右腿同相，右臂与左腿同相。
- 双臂摆幅约 ±25°，双腿摆幅约 ±27°。
- 根节点上下起伏不超过 3 px。
- 桥面纹理与速度线持续向后移动，形成真实前进感。

## 4. 四个操作姿态

### `left` / `right`

- 人物根节点向目标跑道横移。
- 躯干向目标方向倾斜 12–30°。
- 内侧腿蹬地，外侧臂平衡。
- 620 ms 后回到跑步循环。

### `jump`

- 18% 时间内起跳，55% 附近达到最高点。
- 根节点上移约 39 px。
- 双腿向身体收起，双臂抬高保持平衡。
- 末段压缩落地，立即恢复交替跑步。

### `slide`

- 根节点下移，整体高度压缩到约 62%。
- 躯干向前倾斜，双腿一前一后展开。
- 人物从高空横梁下方通过。
- 620 ms 后恢复站立跑步。

## 5. 结束姿态

- `wrong`：双臂张开、躯干失衡，安全刹停。
- `timeout`：双脚前撑、躯干后倾，在障碍前停止。
- `completed`：短冲刺并向远处缩小。

不表现坠落、受伤或暴力碰撞。

## 6. 服务端映射

```text
playing + 未提交          -> run-loop
新快照 lastAction=left   -> left -> run-loop
新快照 lastAction=right  -> right -> run-loop
新快照 lastAction=jump   -> jump -> run-loop
新快照 lastAction=slide  -> slide -> run-loop
finished/wrong           -> stumble
finished/timeout         -> brake
finished/completed       -> finish
```

客户端提交后可以锁住重复输入，但只有服务端推进题目并返回 `lastAction` 后才播放成功动作。

## 7. 减弱动态

`prefers-reduced-motion: reduce` 时停止无限跑步、桥面滚动与速度线：

- 左右变道显示静态倾斜。
- 跳跃显示较小的上移。
- 下蹲显示静态压低姿态。
- 规则、倒计时和服务端判定不变。

## 8. 验收标准

1. 未操作时双腿确实交替运动。
2. 场景滚动与腿部步态同时表达向前跑。
3. W 动画有明显腾空与收腿。
4. S 动画有明显压低与滑行。
5. A/D 动画有横移与身体倾斜。
6. 四个成功动作只在服务端确认后播放。
