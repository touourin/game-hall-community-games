# 卡牌模型与视觉规范

## 1. 建模目标

卡牌模型把角色的规则语义、牌张数量、目标方式、私密信息和原型视觉放在同一个可校验目录中。运行时只能按稳定 `id` 和 `opcode` 判断规则，不能依赖中文名称、数组位置或颜色。

权威数据位于 `model/card-catalog.json`；本文件解释字段和视觉意图。

## 2. 两层身份

- **牌种 `cardTypeId`**：默认档案十一种角色之一，例如 `guard`、`queen`、`princess`。
- **实例 `cardInstanceId`**：一轮中真实存在的副本，例如 `guard-01`、`guard-06`。

牌种决定点数和效果，实例决定所在区域与动作引用。新一轮可复用稳定实例 ID，但战绩必须同时带轮号，避免跨轮混淆。

## 3. 字段说明

| 字段 | 含义 |
| --- | --- |
| `id` | 稳定英文 slug，协议与代码唯一键 |
| `value` | 轮末与男爵比较点数 |
| `nameZh` / `nameEn` | 展示名称；不参与规则判断 |
| `provenance` | 区分官方现行角色和项目自定义皇后 |
| `count` | 21 张现行档案中的副本数 |
| `classicCount` | 16 张经典档案中的副本数 |
| `queenVariantCount` | 默认 22 张皇后扩展档案中的副本数 |
| `effect.opcode` | 服务端效果解释器指令 |
| `effect.timing` | 出牌、弃牌、轮末或合法性检查时点 |
| `effect.targetMode` | 无目标、另一名玩家、任意玩家或自己 |
| `effect.choiceKind` | 角色猜测、玩家目标、保留与牌底排序等 UI 类型 |
| `effect.visibility` | 效果结果的公开范围 |
| `visual` | 原创原型色板、符号和纹样，不是官方美术 |

| 角色 | opcode | 目标 | 选择 | 私密结果 |

| 卫兵 | `guess-hand` | 另一人 | 目标＋非卫兵角色 | 未命中时手牌不公开 |
| 牧师 | `peek-hand` | 另一人 | 目标 | 只对行动者显示目标手牌 |
| 男爵 | `compare-hands` | 另一人 | 目标 | 比较双方看牌面，其他人只见结果 |
| 侍女 | `grant-protection` | 自己 | 无 | 无 |
| 王子 | `force-redraw` | 任意玩家 | 目标 | 新手牌仅目标本人可见 |
| 大臣 | `draw-keep-bottom` | 自己 | 保留 1 张＋排列其余 | 候选与牌底顺序仅行动者可见 |

## 5. 数量与档案

默认 `queen_22` 使用 `queenVariantCount`，即现行 21 张牌加皇后 ×1，合计 22 张；`current_21` 使用 `count`，合计 21 张；`classic_16` 使用 `classicCount`，合计 16 张。经典档案中间谍、大臣和皇后数量为 0，卫兵为 5，其余相同。

卡牌实例由目录顺序稳定生成：`{id}-{两位序号}`。实例生成器必须按规则档案数量创建，不应先创建 22 张后把其他档案的多余实例留在不可见区域。

## 6. 原型视觉系统

本包采用“封蜡信笺与宫廷剪影”的原创功能原型，不复制官方卡面。

- 画幅：宽高比约 `2:3`，逻辑尺寸 `112 × 168`。
- 左上与右下同时显示大号点数，倒置观察也可确认。
- 顶部显示中英文角色名，中部使用抽象符号，底部放简短效果摘要。
- 左边缘的圆点列表示牌组中该牌种的副本数；经典版差异用文字标签，不模仿官方黄色点阵。
- 每张牌同时拥有颜色、符号和文字名称，不以颜色作为唯一识别方式。

## 7. 状态表现

卡牌组件至少支持：

- `face-down`：只显示原创统一牌背；
- `face-up`：公开角色、点数和效果；
- `selectable` / `selected`：键盘和指针均可操作；
- `forced`：伯爵夫人强制时显示“必须打出”，但不解释另一张牌；
- `disabled`：说明不可选择原因；
- `private-peek`：牧师／男爵的临时私密展示；
- `chancellor-candidate`：大臣候选，支持选择保留与牌底排序；
- `discarded`：显示弃牌原因；
- `elimination-trigger`：公主触发时显示图标与文字，不只闪红。
- `guard-hit-redraw`：皇后被卫兵命中时显示“免于淘汰，弃牌重抽”，不可播放淘汰动画。

## 8. 文案限制

运行时短文案只做提示，详细裁决以规则帮助为准。建议：

- 卫兵：“猜一名对手的角色（不能猜卫兵）。”
- 牧师：“私下查看一名对手的手牌。”
- 男爵：“秘密比点，较低者出局。”
- 侍女：“直到你的下回合前不受他人牌效影响。”
- 王子：“令任意玩家弃牌并重摸。”
- 大臣：“抽至多两张，留一张，其余压到牌底。”
- 国王：“与一名对手交换手牌。”
- 皇后：“与国王／伯爵夫人同手时必须打出；打出后猜牌；被卫兵猜中则重抽。”
- 伯爵夫人：“与国王或王子同手时必须打出。”
- 公主：“打出或弃掉时，你出局。”
- 间谍：“若你是轮末唯一仍在局的间谍玩家，额外得 1 标记。”

## 9. 扩展边界

主题换皮或其他 Love Letter System 游戏不能只替换名称和插画：它们可能改变牌数、目标、胜利条件或阵营。若未来支持，应新建 `gameId` 和卡牌目录，不向本目录追加非基础角色。
