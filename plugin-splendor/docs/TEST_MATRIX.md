# 测试覆盖矩阵

## 1. 组件与开局

- 90 个唯一发展卡，等级为 40/30/20，每种奖励色 18 张；10 个贵族为五个 4+4、五个 3+3+3。
- 2/3/4 人供应分别为五色各 4/5/7，黄金恒为 5；市场每级 4 张，贵族为人数加一。
- 固定种子可复现牌序、行动轨迹和结果；1 人、5 人及非常规规则档案拒绝开局。
- 每次动作后验证 90 张发展卡、10 位贵族和六色棋子守恒。

## 2. 四种主要行动

- 不同色：5/4/3/2/1/0 种非空供应，错误数量、重复颜色、黄金和空供应。
- 同色：行动前供应为 5/4/3 的允许边界，黄金拒绝。
- 保留：市场来源、盲抽来源、黄金有货/无货、0–3 张上限、空牌堆、市场空槽、陈旧市场版本。
- 购买：市场与保留牌、正常支付、免费购买、主动黄金替代、市场补牌及空牌堆不补。

## 3. 精确支付与上限

- 同色奖励只减同色费用；奖励超过费用时实际费用归零。
- 黄金必须精确等于未由彩色宝石支付的实际费用；允许持有对应宝石时主动改用黄金。
- 拒绝欠付、超付、不完整向量、负数、布尔值和超过持有数量的支付。
- 主动作可以暂时超过 10 枚；随后只接受恰好归还超额数量，可归还黄金或旧棋子。

## 4. 贵族与终局

- 贵族只计算已购买发展卡的永久奖励，不计算棋子、黄金或保留牌。
- 单一合资格贵族自动获得；多个时保存不可变候选并强制选 1；每回合最多 1 位。
- 首家、中间席和首家右手边分别触发 15 分时，最终轮行动边界正确。
- 更高威望优先；同威望时发展卡更少者获胜；两项都相同则返回全部共同赢家。
- 玩家退出、仅剩一人和强制步骤中退出均保持组件守恒并完成平台结算。

## 5. 隐私、界面与动画

- 对手视图和公开事件不包含盲保留牌 ID、牌堆顺序或未使用贵族顺序；公开保留牌持续可见。
- 2/3/4 人相对座位、12 个市场槽、6 种供应、本人引擎和最多 3 个保留槽稳定渲染。
- 取不同色、取同色、公开保留、盲保留、市场购买、保留牌购买、支付替换、归还和贵族选择均验证 payload。
- 十类服务端事件逐项映射到有界动画；动画不会拦截指针，减少动态效果时立即呈现最终状态。
- 1440/1024/768/390/320 像素视口检查页面水平溢出、牌/棋子/面板交叠和强制弹层可达性。

## 6. 整局模拟

- 每个支持人数运行多种固定种子的真实引擎完整局。
- 自动玩家只读取安全视图并提交公开 action，不调用结算捷径。
- 每局要求进入 `finished`、最高分至少 15、赢家按独立比较器复算一致，且实际发生取棋子和购买。
