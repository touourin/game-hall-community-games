# 动画与防穿模模型

运行时动画只消费服务端公开事件，不反推规则状态。`model/animation-catalog.json` 是事件到表现的映射；每个事件带单调递增的 `sequence`，前端按序排队，一次只播放一个。

## 分层

| 层 | z-index | 内容 |
| --- | ---: | --- |
| 动画平面 | 16 | 飞行牌背、配对、洗序、传牌、图标粒子 |
| 环形座位 | 20 | 4–8 人玩家牌背与公开状态 |
| 中央视图 | 22 | 回合提示、固定来源牌序、果效选择 |
| 自己手牌 | 28 | 完整固定顺序、保护标记与最右落点 |
| 规则/结算 | 80 | 模态规则、事件历史与最终老鳖揭晓 |

动画平面设置 `overflow: hidden`、`contain: layout paint` 与 `pointer-events: none`。所有运动都被裁在桌面安全区，且永远位于座位、操作窗和真实手牌下方，因此不会穿过可交互卡牌，也不会挡住点击。

## 公开信息边界

- 正常暗抽、额外暗抽、甜蜜分享、对半交换和流水果摊在公共动画中只使用统一牌背。
- 只有已经公开弃掉的对子可以在配对动画中显示水果主体。
- 偷瞄动画仅显示眼睛图标；完整牌面只进入发动者的私密视图。
- 最终揭晓只在服务端确认 `removedPairCount = 30` 且效果队列为空后显示。

## 响应式防碰撞

- 桌面 4–8 人围绕椭圆桌按视角旋转，自己固定在底部，其他坐标保持唯一。
- 650px 以下对手座位收成紧凑信息牌，隐藏装饰性迷你牌列；中央操作区缩为 64vw。
- 自己的手牌不压缩顺序，而是使用水平滚动，因此大量手牌仍有稳定的位置号。
- `prefers-reduced-motion: reduce` 时隐藏非必要动画层，但规则状态和事件文字保留。
