# 《算途疾行》玩家模型

> 第三人称完整角色、八帧奔跑、双帧转弯、跑酷与失败姿态 v4.0

## 1. 角色定位

“逐光者”是第三人称桥面跑者。原创身份与服装参考位于 `images/runner-character-concept.png`；第二代运行时动作图集位于 `frontend/assets/runner-animation-atlas-v2.png`，左右转向使用 `frontend/assets/runner-turn-atlas-v2.png`。两张图集保持同一名年轻跑者、黑色乱发、炭灰短夹克、橙色滚边、象牙色内层、深色长裤和青色腕表，并为失败反馈补齐撞墙与坠桥姿态。

## 2. 动作图集

图集为 `1254 × 1254` 透明 PNG，严格划分为十六个等分单元：

| 单元 | 姿态 | 运行时职责 |
| --- | --- | --- |
| 第 1–2 行 | 向前跑 1–8 | 一个完整步态周期，左右脚推进与腾空连续变化 |
| 第 3 行左半 | 左转 1–2 | 躯干、髋部和落脚方向向左倾入弯道 |
| 第 3 行右半 | 右转 1–2 | 躯干、髋部和落脚方向向右倾入弯道 |
| 第 4 行第 1 格 | 跳跃 | 腾空并收起双腿 |
| 第 4 行第 2 格 | 低姿滑行 | 身体压低、一腿伸展、一腿收起 |
| 第 4 行第 3 格 | 撞墙 | 双手前撑、身体后仰，配合冲击碎片 |
| 第 4 行第 4 格 | 坠桥 | 失去支撑并向画面右下方翻落 |

转向图集为 `1254 × 1254` 透明 PNG，分成四个 `627 × 627` 单元。运行时使用左上植步帧衔接动作，左下为左深倾，右上为右深倾，确保两个方向不会误用跳跃或滑行动作。

运行时只显示一个完整人物轮廓，不拼接头、躯干和胶囊形四肢。模型根节点位于画面下方桥面接触点，逻辑宽度按场景在 158–224 px 间响应式变化。

## 3. 奔跑循环

- 周期随等级从 720 ms 缩短到 430 ms。
- 八个完整步态以离散帧循环，腿、髋、肩和手臂连续改变，而不是整张图只上下抖动。
- 人物只保留约 2 px 的轻微重心起伏；脚下接触影和两条短速度尾迹与步频同步。
- 稀疏路面碎石和护栏路标持续向镜头移动，与步态共同表达人物真实向前跑。

## 4. 四个操作姿态

### `left` / `right`

- 立即切换为对应方向的完整转弯姿势。
- 人物根节点沿目标跑道横移，镜头和桥面向反方向轻转。
- 身体、髋部、手臂和落脚方向全部进入弯道，而不是只将直立人物旋转。
- 660 ms 后回到八帧奔跑。

### `jump`

- 16% 时间内起跳，52%–62% 位于最高点。
- 根节点上移约 94 px，显示专用收腿腾空姿势。
- 接触影缩小并变淡，末段落回桥面后恢复跑步。

### `slide`

- 显示专用低姿滑行动作，人物轮廓上提并适度放大，确保在深色桥面上仍清楚可见。
- 身体保持在高空横梁下方，一腿伸展、一腿收起。
- 桥面产生轻微反向镜头位移，680 ms 后恢复跑步。

## 5. 结束姿态

- `wrong`：所选动作为 `left/right` 时播放 1250 ms 坠桥；所选动作为 `jump/slide` 时播放 980 ms 撞墙。
- `timeout`：按正确动作对应的路线选择撞墙或坠桥反馈。
- `completed`：保留奔跑帧并向消失点缩小。
- 失败动画完成前隐藏结算卡，防止覆盖人物和场景反馈。

## 6. 服务端映射

```text
playing + 未提交          -> run-1 -> ... -> run-8
新快照 lastAction=left   -> left -> run-loop
新快照 lastAction=right  -> right -> run-loop
新快照 lastAction=jump   -> jump -> run-loop
新快照 lastAction=slide  -> slide -> run-loop
finished/wrong           -> selected route -> wall-impact / cliff-fall
finished/timeout         -> correct route -> wall-impact / cliff-fall
finished/completed       -> run-frame + finish
```

客户端提交后可以锁住重复输入，但只有服务端推进题目并返回 `lastAction` 后才播放成功动作。

## 7. 减弱动态

`prefers-reduced-motion: reduce` 时停止八帧循环、路面流动、速度尾迹和失败粒子：

- 保留一张静态跑步帧。
- 左右、跳跃和低姿滑行使用对应完整姿态与较小静态位移。
- 规则、倒计时和服务端判定不变。

## 8. 验收标准

1. 未操作时八个完整奔跑姿态确实循环，腿部位置清楚变化。
2. 稀疏路面碎石和双侧路标持续向镜头移动，不依赖人物原地抖动表达速度。
3. W 动画能看到完整腾空与收腿。
4. S 动画能看到明显压低与滑行。
5. A/D 动画能看到专用转弯姿势、横移和镜头转向。
6. 四个成功动作只在服务端确认后播放。
7. 左右路线失败表现为坠桥，中间跑酷动作失败表现为撞墙，且结算卡在动画完成后才出现。
