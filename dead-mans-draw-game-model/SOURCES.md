# 规则来源与版本取舍

检索与核对日期：2026-09-02。

## 1. 核心来源

1. [Mayday Games 产品页](https://www.maydaygames.com/products/dead-mans-draw)：当前发行方页面，确认 2–4 人、10–15 分钟、60 张战利品牌、17 张特性牌，以及重复花色爆牌的核心规则；页面还公开了桌面可用的网页变体。
2. [Mayday Games 官方规则 PDF](https://cdn.shopify.com/s/files/1/1098/0948/files/DMD_Rulebook.pdf?14247438916855222815=)：本建模的主要规则依据。用于核对准备流程、完整回合、十种花色、十七种特性、计分、同分裁决与美人鱼变体。
3. [Mayday Games 开发说明](https://www.maydaygames.com/blogs/news/dead-mans-draw-development-notes)：由规则书开发者说明实体版与 Stardock 数字版的关键差异。实体版中抓钩、弯刀和藏宝图可以迫使玩家爆牌；数字版会过滤会导致爆牌的候选。
4. [Stardock / Steam 产品页](https://store.steampowered.com/app/262450/Dead_Mans_Draw/)：确认数字版的设计者／发行者信息、十八种数字版特性，以及 PC 版美人鱼能力和海妖特性。
5. [BoardGameGeek 游戏条目](https://boardgamegeek.com/boardgame/149155/dead-mans-draw)：用于交叉核对发行年份、规则文件目录和版本信息，不作为冲突规则的最高优先级来源。
6. [中文规则整理：亡者神抽](https://boardgame-record.blogspot.com/2014/01/dead-mans-draw.html)：用于核对中文社区惯用译名和早期 Print-and-Play 规则提示；遇到差异时服从 Mayday 当前规则书。

## 2. 本包采用的版本

默认 `tabletop_base_2015` 以 Mayday 官方实体规则为准：

- 抓钩、弯刀和藏宝图加入的牌也会检查爆牌；若形成重复花色，立即爆牌。
- 抽到导致爆牌的牌不执行其花色能力。
- 基础美人鱼没有主动能力，点数为 4–9。
- 特性牌开局每人获得两张，选择一张公开并在整局持续生效。

`digital_safe_2014` 只用于兼容 Stardock 数字体验：

- 抓钩、弯刀和藏宝图只提供不会立即爆牌的合法候选；没有合法候选时能力失效。
- 美人鱼能力是否启用由单独开关控制，避免把“安全候选”与“PC 美人鱼”绑定成不可拆分的一套规则。

`tabletop_mermaid_variant` 在实体基础版上替换美人鱼 8、9 为 2、3，并启用“重演场上一张较早的牌”的能力，同时把海妖特性加入特性牌池。

2026 年十周年纪念版含新增卡牌与勘误换牌。其专属内容不在本建模范围内；在拿到稳定、最终且无勘误的官方卡表前，不应混入基础牌池。

## 3. 冲突处理优先级

`当前发行方规则 PDF > 当前发行方产品页 > 发行方开发说明 > 设计方数字产品页 > 早期 PnP／社区资料`

若来源仍未覆盖，软件必须采用可重复、可测试且不会泄露隐藏信息的明确裁决，并在规则说明书标注“数字化裁决”，不能假装是官方原文。

## 4. 已明确的数字化裁决

| 问题 | 本包裁决 | 理由 |
| --- | --- | --- |
| 海怪是抽牌堆最后一张，仍欠强制入场牌 | 抽牌堆为空且没有正在结算的入场效果时，剩余强制数量清零，当前玩家可以收牌 | 官方允许抽到最后一张的玩家正常完成回合，但未说明无法履行的海怪数量 |
| 钥匙／宝箱数量大于弃牌堆 | 取走弃牌堆全部剩余牌，不从其他区域补足 | 遵循“尽可能完成”且保持组件守恒 |
| 船锚保护的牌中同时有钥匙和宝箱，随后爆牌 | 受保护部分视为一次收牌，并按实际收下张数触发奖励 | 早期规则提示明确给出 `钥匙、宝箱、船锚、钥匙` 示例 |
| 多个网页变体能否叠加 | 正式房间一次最多选择一个全局变体 | 官方没有给出所有组合的优先级，限制组合可避免未定义冲突 |
| 变体与特性冲突 | 由 `rules-profiles.json` 的显式优先级表裁决；未列出的组合禁止开局 | 例如“贼岛”与“戴维·琼斯的魔柜”争夺爆牌去向 |

## 5. 权利边界

- 规则文字全部重新组织为面向实现的中文表述，没有复制官方版式。
- 卡牌原型只表达花色、点数、能力类别和交互层级，不复刻官方人物、插画、Logo、纹样或牌背。
- 来源链接用于规则追溯；官方 PDF 不随本目录再分发。
- 若用于公开发布，应由项目维护者进一步审查名称、商标、素材授权和当地法律要求。
