# 亡命神抽测试矩阵

本矩阵针对 `tabletop_base_2015` 常规规则。每个自动测试动作后都会执行组件守恒断言：
60 张战利品牌必须且只能存在于抽牌堆、弃牌堆、玩家银行或当前结算区之一。

## 1. 人数、开局与信息边界

| 范围 | 覆盖 |
| --- | --- |
| 人数 | 2、3、4 人合法；1、5 人拒绝 |
| 牌堆 | 50 张洗牌抽牌堆、10 张各花色最低牌进入弃牌堆 |
| 首家 | 房主与随机首家选项 |
| 配置 | 只接受 `tabletop_base_2015`；拒绝数字安全版与未实现变体 |
| 特性 | 每人两项私密候选、不可选择他人候选、同时公开、魔柜目标选择 |
| 并发 | 旧 `revision`、非当前玩家操作、伪造／过期选择均拒绝且不改变状态 |
| 视角 | 抽牌顺序、内部效果栈和其他玩家未公开特性不会进入玩家视图或记录状态 |

## 2. 十种花色与爆牌

| 花色 | 正常能力 | 无候选／边界 | 强制爆牌 |
| --- | --- | --- | --- |
| 船锚 | 保护此前航道牌 | 首张船锚 | 后续重复花色仅保留保护区 |
| 抓钩 | 从自己银行取一张入场并连锁 | 空银行 | 取回重复花色会爆牌 |
| 大炮 | 击沉对手银行一张 | 无对手牌 | — |
| 钥匙 | 与宝箱共同收牌时从弃牌堆奖励 | 弃牌堆不足时全取 | 受保护组合先领奖励再沉没未保护牌 |
| 宝箱 | 与钥匙共同收牌时从弃牌堆奖励 | 弃牌堆为空 | 同上 |
| 藏宝图 | 弃牌堆随机翻三选一入场 | 候选不足时尽可能翻 | 实体规则保留会爆牌候选 |
| 水晶球 | 公开预览下一张 | 抽牌堆已空 | — |
| 弯刀 | 从对手银行取同点数牌入场 | 无匹配点数 | 取回重复花色会爆牌 |
| 海怪 | 强制再进入两张牌 | 抽牌堆提前耗尽时清零未履行债务 | 债务期间仍执行入场与爆牌 |
| 美人鱼 | 基础版无主动能力，点数 4–9 | 抽牌堆末牌 | 重复花色正常爆牌 |

爆牌测试另覆盖：导致爆牌的牌不发动能力、船锚／吝啬鬼／避风港保护分区、
戴维·琼斯的魔柜改写未保护牌去向，以及爆牌后正确换手。

## 3. 十七种特性

自动测试逐项覆盖：金天平、卡萨诺瓦、掠夺者、寻宝者、领航员、炮术大师、拾荒者、
神秘主义者、剑术大师、吝啬鬼、铁钩船长、避风港、渔夫、驯兽师、哑火、格挡、
戴维·琼斯的魔柜。组合优先级覆盖“哑火覆盖炮术大师”和“格挡使弯刀失去合法目标”。

## 4. 终局与胜负

| 情况 | 期望 |
| --- | --- |
| 正常牌堆耗尽 | 最后一张仍完整结算；当前玩家可收牌后才进入终局 |
| 卡萨诺瓦直入银行抽走末牌 | 空航道不死锁，立即终局 |
| 末牌海怪 | 无法履行的债务清零，可收牌并终局 |
| 主动退出／断线超时 | 弃置未完成航道，跳过退出者；只剩一人时直接获胜 |
| 当前玩家在空牌堆时退出 | 不开始幽灵回合，按牌堆耗尽结算 |
| 计分 | 每花色只取最高牌；金天平给计分美人鱼 +5 |
| 同分 | 先比较银行牌总数；仍相同时共享胜利 |

## 5. 完整局随机模拟

2、3、4 人各运行 32 个固定种子，共 96 局启用特性的完整游戏。每局最多 1200 个动作；
机器人只使用其玩家视图暴露的合法操作。每一步验证组件守恒，终局使用独立计分器复算总分、
牌数与胜者。所有 10 种花色必须在模拟事件中至少入场一次。

## 6. 前端与动画

组件测试覆盖：

- 2／3／4 人座位与每位玩家的 10 个银行花色槽。
- 宽屏二人北席、三人西／东席、四人西／北／东席；中小屏按模型折叠为顶部栏。
- 翻牌、收牌、特性选择和服务端授权效果选项的事件载荷与修订号。
- 船锚、抓钩、大炮、钥匙、宝箱、藏宝图、水晶球、弯刀、海怪、美人鱼各自的动画类。
- 爆牌、保护拆分、钥匙宝箱奖励、卡牌转移、回合切换、终局共享胜利覆盖层。
- 模型色板、`1179 / 759 / 390` 断点和减少动态效果媒体查询。

真实浏览器巡检在 2、3、4 人预览和完整自动对局上执行，并检查 1440×1000、1024×768、
768×900、390×844、320×568 视口：页面不得产生水平穿模，关键操作必须在视口内可达，
特性／效果／结算覆盖层不得被牌桌裁切，动画层不得拦截指针事件。
