# 庞氏骗局测试矩阵

查验日期：2026-09-02。规则目标为 Bright Eye 标准玩法：3–5 人、默认奢侈品、首轮跳过暗盘。

## 自动规则与结算

| 范围 | 覆盖用例 | 判定 |
|---|---|---|
| 3／4／5 人完整局 | 真实状态机从募集循环到首次破产；每个动作后核对 72 张资金牌、60 枚产业与 4 件奢侈品守恒 | 通过 |
| 正常付息 | 未到期、单张到期、多张同时到期、现金恰好付至 0、现金少 1 | 通过 |
| 崩盘付息 | 玩家数阈值 3／4／5、双格推进、越过箭头只付一次、后续牌停在下一格 | 通过 |
| 产业弃置 | 唯一最大、多个产业并列最大、零产业自动跳过 | 通过 |
| 单人破产 | 破产者剔除计分，存活者按分数排序 | 通过 |
| 多人同时破产 | 同一付息快照内同时标记，其他存活者结算 | 通过 |
| 全员同时破产 | 无胜者，原因明确为“所有玩家同时破产” | 通过 |
| 唯一最高分 | 逐产业三角数加奢侈品分 | 通过 |
| 总分同分 | 比较持有的最高金额资金牌 | 通过 |
| 完全同分 | 总分与最高资金牌均相同时并列获胜、共享第 1 名 | 通过 |
| 兼容计分 | 现金 30／56／78／96 的上下边界，且不叠加奢侈品 | 通过 |
| 暗盘结算 | 正金额接受／反向，现金不足反向，0 元接受／反向，负数、布尔、浮点、字符串和空值拒绝 | 通过 |
| 隐私 | 对手现金为空；暗盘金额只给双方；公开事件和记录视图不泄漏报价 | 通过 |
| 退出／超时 | 立即按破产处理，存活者照常计分；重复超时无副作用 | 通过 |
| 牌库边界 | 起始牌永久移出、普通牌进弃牌、空牌库回收弃牌且无重复、事件带上限 80 | 通过 |

## 前端与动画

组件测试覆盖九张市场牌、产业、奢侈品、挡板现金、五格时间轮、3–5 个玩家账簿和终局审计。事件到动画的映射逐项验证：

`fund`、`trade_offer`、`trade_accept`、`luxury`、`market_discard`、`market_crash`、`crash_discard`、`interest_paid`、`wheel`、`bankruptcy`、`marker_pass`。

复合结算中的多个事件按序播放，不会只保留最后一个。固定到期箭头是旋转轮盘的兄弟节点，不随盘体旋转。初次进入页面不重播历史事件；系统启用减少动态时，所有动画与过渡缩短到近零。

## 视觉一致性

回归画面与 `component-concept.png`、`table-scene-concept.png` 和 `clandestine-trade-process.png` 逐项比对。实现保留瓶绿桌毡、旧象牙卡、黄铜线、深蓝账房面板、四色产业、五格轮盘、挡板、钞票和牛皮纸信封；界面没有复制商业版盒绘、人物照片或商标。
