# 数字版裁定与实现边界

本文件只记录数字平台必须固定、但原版规则未明确覆盖的行为。它们不是原版规则勘误，也不应混入“官方规则”描述。

## 1. 首位玩家

实体规则规定首航由最年长者开始拍卖。平台不采集年龄，因此使用房间的首位玩家设置：

- `random`：服务端在开局时随机选拍卖发起人；
- `host`：房主成为拍卖发起人。

后续航行始终由上一航行的港务长开始拍卖。

## 2. 首航无人叫价

原文只规定“无人叫价时上一任港务长留任”，但首航没有上一任。数字版采用可终止的回退：

1. 首航所有人均 Pass 时，首航拍卖发起人以 0 比索成为港务长；
2. 后续航行所有人均 Pass 时，上一任港务长以 0 比索留任；
3. 该回退写入事件日志，界面明确显示“无人叫价，港务长留任/由发起人担任”。

这样不会强迫玩家在资金不足时制造非法叫价，也不会让状态机停住。

## 3. 平局

原规则只说财富最高者获胜，没有提供同分破局条件。数字版将所有最高财富玩家列为共同获胜者，不以剩余现金、未抵押份额、港务长身份或座次暗中破局。

## 4. 公开与私密信息

| 信息 | 本人 | 对手 | 中立公共视角 |
| --- | --- | --- | --- |
| 自己的份额种类 | 可见 | 不可见 | 不可见 |
| 每人份额总数 | 可见 | 可见 | 可见 |
| 每人抵押份额数量 | 可见 | 可见 | 可见 |
| 被抵押份额的具体种类 | 仅本人可见 | 不可见 | 不可见 |
| 现金 | 可见 | 可见 | 可见 |
| 市场余量（按货物计数） | 可见 | 可见 | 可见 |
| 骰点、船位、助手、出价与付款 | 可见 | 可见 | 可见 |

现金在实体局中可由公开付款完整追踪，数字版直接公开，避免记忆优势。卡牌实例 ID 只进入本人视图和服务端真值。

当前宿主的观战模式可能绑定某个玩家视角，因此第一版插件建议关闭 `spectators`。只有宿主能保证调用真正的中立投影时，才能启用本模型已经定义的 spectator 视图。

## 5. 港务长的移动次序

原规则允许港务长在看到三个骰点后，以任意顺序移动三艘船。次序会决定同一轮中多船抵达时谁进入港口 A、B、C。

数字版在骰点公开后要求港务长提交三艘未结算船的排列：

`choose_move_order { puntIds: ["punt-2", "punt-1", "punt-3"] }`

服务端验证它恰好是所有未结算船的一次排列，再依次结算。客户端不能直接提交新位置或目的港槽位。

## 6. 随机与日志

- 发牌、首位玩家和骰点只由服务端安全随机源产生。
- 每次随机事件记录输入阶段、结果和单调递增事件号，支持重连和赛后审计。
- 客户端动画使用事件号去重，动画完成与否不推进规则。
- 正式回放能力只有在宿主 API 支持并完成隐私审计后再开启。

## 7. 贷款动作时机

实体规则允许随时贷款或赎回。为了避免多人实时“插话式动作”，数字版把自愿财务动作限制在玩家拥有操作优先权时，以及航行总结页：

- `take_loan { shareId }`：抵押一张本人未抵押份额，获得 12；
- `repay_loan { shareId }`：支付 15，解除该份额抵押；
- 必须付款但现金不足时，服务端进入强制补款子流程，要求抵押足够的份额；若保险责任超过全部可用资金，则按原规则由港口现金箱补足余额。

这一时机限制不改变贷款价格、终局扣款或任何概率，只减少并发竞态。

## 8. 免票助手

服务端按“当前所有合法空位中的最低正常成本”判断资格：

`cash + 12 * unencumberedShareCount < minimumLegalPlacementCost`

符合资格时，玩家可以把助手放到任意合法空位（保险除外）：

- 现金为 0 时不付费；
- 现金大于 0 但仍低于最低合法成本时，支付全部剩余现金；
- 该助手在之后的收益、登船、被逐下船等方面与正常助手完全相同；
- 事件日志标记 `blindPassenger: true`，只用于解释，不改变结算。

## 9. 退出、掉线与超时

- 第一版不提供会改变规则状态的自定义“认输”动作。
- 掉线玩家的座位和私密状态保留，重连后从服务端快照恢复。
- 不在规则引擎中偷偷替玩家购买、部署、登船、引航或决定劫船去向。
- 如果产品以后要求回合超时，默认动作必须在房间规则中显式展示，并为海盗船长去向等高影响选择单独评审。

## 10. 银行与硬币

数字版使用整数比索账本，不模拟硬币枚数短缺。所有付款和收入生成结构化账目；不允许负现金。港口现金箱补足保险缺口时记录 `bankCoverage`，玩家不为该补足额新增债务。

## 11. 美术与历史语境

运行时使用原创的港口、航线、货箱和抽象贸易凭证，不复刻官方卡面或版图。背景文本只作为原作设定摘要，不把殖民统治、走私或海盗行为包装成历史事实说明。
