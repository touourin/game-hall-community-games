# 视觉设计稿

本目录保存《算途疾行》的原创视觉建模图，仅作为场景、角色、动画和题目展示面的设计依据；运行时游戏使用 `frontend/` 内的响应式 DOM/CSS 模型，不把大图作为场景背景。

| 文件 | 用途 |
| --- | --- |
| `scene-concept.png` | 云上算轨世界、跑道材质和十字节点总览 |
| `runner-character-concept.png` | 同一跑者的站立、奔跑与左右转弯姿态 |
| `crossroads-question-gates.png` | 开放路线、封闭障碍与空白题牌近景 |

图像由 OpenAI 内置 `imagegen` 工具生成。完整提示词、约束和入口图标说明见 `../SOURCES.md`。
