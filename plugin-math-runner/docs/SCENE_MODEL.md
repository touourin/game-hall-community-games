# 《算途疾行》桥面场景模型

> 三跑道云桥、2/3 路分叉、上下障碍与宿主布局 v2.0

## 1. 镜头

- 第三人称追逐镜头，略微俯视。
- 消失点位于画面水平中心约 30% 高度。
- 人物位于底部中心，题牌位于 24%–38% 高度。
- 所有跑道从人物附近向消失点收束，明确表达持续向前。

远景使用 `frontend/assets/runner-bridge-backdrop.png`，只提供峡谷、城市、日落和中央桥梁气氛；运行时跑道、题牌和障碍均由 DOM/CSS 绘制。

## 2. 桥面

- 主桥使用石墨复合板和暖金属护栏。
- 两条青色纵向接缝把桥面分成左、中、右三条跑道。
- 接缝纹理按等级周期向后滚动。
- 左右外缘始终有护栏；断桥只出现在题段远端，不让人物表现坠落。

## 3. 分叉

每题服务端从三个槽位中开放 2 条或 3 条：

```text
          消失点
    左道   中道   右道
      \     |     /
         跑者
```

- 开放跑道：完整桥板、玻璃题牌和动作键提示。
- 封闭跑道：断裂轮廓、斜纹和“断桥”视觉标记。
- 不绘制向天空或向地面的道路。
- 画面中的“2 路分叉 / 3 路分叉”雷达直接来自服务端 `branchCount`。

## 4. 障碍

只有中间跑道使用垂直障碍：

| 障碍 | 轮廓 | 动作 |
| --- | --- | --- |
| 地面障碍 | 三个低矮琥珀块 | W / jump |
| 高空障碍 | 两立柱 + 横梁，下方留空 | S / slide |

障碍与题牌动作一一对应。同一中间跑道不会同时出现两种障碍。

## 5. 题牌

- 每条开放跑道只有一块题牌。
- 题牌保持正对屏幕，不随桥面透视扭曲，优先保证算式可读。
- 题牌包含键帽、箭头、动作名、等式和跑道名。
- 答对后正确题牌显示勾；错答时所选题牌显示叉。

## 6. 人物与前进感

- `RunnerModel` 位于桥面底部中心。
- 双腿和双臂分别动画，不使用整体图片上下抖动代替跑步。
- 桥面纹理、速度线和角色步频同时随等级加速。
- A/D 使人物横向移动并倾斜。
- W 使人物明显腾空收腿。
- S 使人物压低并滑过横梁。

## 7. 宿主返回按钮

普通模式下插件根节点：

- 使用 `position: relative`；
- 保持在 `arcade-game-stage` 内；
- 高度为视口减去宿主房间头部；
- 不写入 `html` / `body` class；
- 不覆盖宿主 `RoomExitButton`。

因此“返回/放弃并退出”由宿主执行，可正确通知服务端并返回大厅。只有用户主动进入浏览器 Fullscreen API 时插件才固定占满屏幕。

## 8. 响应式

- 桌面：场景在左，控制台在右。
- 低高度横屏：压缩头部、题牌和角色尺寸，保持一屏。
- 手机竖屏：显示旋转横屏提示。
- 全屏：插件内部提供退出全屏按钮；退出后宿主返回按钮恢复可见。

## 9. 减弱动态

减弱动态时停止桥面滚动、速度线和循环步态，但保留静态三跑道、断桥、障碍、题牌、倒计时与结果标记。
