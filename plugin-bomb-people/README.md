# 炸弹超人（plugin-bomb-people）

这是一个完全封装在第三方插件目录内的 2–8 人实时炸弹对战游戏。插件不导入主大厅内部模块，也没有修改主大厅、房间、Socket、账号或公共战绩代码。

## 已实现玩法

- 所有逻辑地图严格为 `20 × 20`，一个固定障碍、可破坏箱或落石只占一格。
- 服务端以 20 Hz 推进权威状态、以 10 Hz 发布快照；本地角色使用最多领先一格的碰撞感知预测立即响应方向键，远端角色继续使用 GPU 位移插值。移动、炸弹、拾取、淘汰和落石最终均由服务端判定。
- 方向键轻点会可靠排队且只移动一格；松键会立即终止本地过渡、发送并补发一次停止状态，服务端也不会在输入归零后继续发布虚假的“移动中”尾帧。窗口失焦、页面隐藏或玩家掉线会清空输入。画面同步频率与服务端快照频率一致，同一玩家最多只有一个同步请求在途；时钟玩家变慢时，其他可见玩家会自动补位，避免请求积压或低性能电脑重复渲染整张地图。
- 普通炸弹放置后最多 2 秒爆炸，十字火焰会被固定障碍和落石阻挡，并可连锁引爆其他普通炸弹。
- 拾取遥控定时炸弹后永久获得一个独立的额外炸弹槽：普通容量用满后再按空格部署，炸弹不会倒计时或被火焰连锁引爆，只能由所有者按 `C` 引爆；引爆后槽位保留，可继续部署下一枚。
- 可破坏箱有 38% 概率掉落道具，玩家走过道具时自动拾取。落地道具没有消失倒计时，也不会被炸弹火焰清除，会保留到被拾取、本格被决胜落石覆盖或本局结束。
- 每 10 秒进行一次 24% 概率的全图随机装备刷新判定。
- 脚踢雷自动触发；拳击手套会即时打雷，扔雷手套则需第一次按 `X` 拿起面前炸弹、第二次按 `X` 才沿当前朝向投出。抱雷期间可继续移动，炸弹的剩余引信会冻结，投出或落地后再继续倒计时；三种方式都可以操作任意玩家的炸弹，后续淘汰计给最后操作者。
- 角色由躯干、左腿和右腿三个视觉层组成，移动时双腿交替迈步并带身体重心、落脚阴影和扬尘，不再以整张立绘平移表现。
- 埋雷、十字爆炸、炸弹滚动、脚踢、拳套击打、弯腰拿雷、双手抱雷移动和抛物线投雷都有独立动画。动作同步只用于画面呈现，不写入对局动态，也没有角色台词或语音。
- 埋雷、爆炸、脚踢、拳击、拿雷和扔雷分别使用固定的非语音音效；同一种动作不区分玩家，始终播放同一种声音。浏览器会在首次键盘或触屏操作后启用音效。
- 对抗开始 90 秒后进入落石决胜：从左上角开始，沿外圈顺时针逐格放石，再逐圈向中心收缩。被落石压中直接阵亡。
- 幽灵相位拾取后在本局永久生效，只能穿过可破坏箱墙，不能穿固定石块或决胜落石；可在箱墙格内放雷，爆炸会同时摧毁所在箱墙。
- 每次新一局开始时由服务端从全部地图中随机抽取，并排除上一局地图，保证连续两局不会重复。
- 每位玩家显示本局击杀、房间累计击杀、夺冠数和胜率；结算通过 `record_state()` 保存击杀明细，通过 `scoreKind: outcome` 进入大厅胜负/胜率统计。

## 操作

| 按键 | 功能 |
|---|---|
| `W A S D` / 方向键 | 上、左、下、右逐格移动 |
| `Space` | 放置普通炸弹；普通容量已满且拥有遥控定时炸弹时，再部署额外的一枚遥控雷 |
| `C` | 引爆自己的遥控定时炸弹 |
| `Z` | 拳击手套即时把面前炸弹打出最多三格 |
| `X` | 第一次拿起面前炸弹；可抱雷移动，再按一次沿当前朝向投出最多四格 |
| 无需按键 | 拥有脚踢雷后，走向炸弹即可让其持续滚动 |

电脑版会隐藏触屏控件，直接监听浏览器键盘完成全部对局操作；键盘无需先点击棋盘获取焦点。移动端使用左侧拖动摇杆移动，右侧动作键负责拳击、放雷、遥控引爆和拿雷/投雷（未获得遥控雷时隐藏 `C` 键）；脚踢雷在朝炸弹移动时自动触发。抱雷会占用双手，此时不能放雷、遥控引爆或用拳套；若没有合法投掷落点，玩家会继续抱雷。普通炸弹被拿起时冻结剩余引信，成功投出或因退出、阵亡、失去手套而落地后，才从原剩余时间继续倒计时。进行中的移动端对局会固定为单屏布局，隐藏次要侧栏并阻止页面上下滚动。玩家、观众和阵亡者之间的操作权限由服务端再次校验。

所有玩家会看到相同的动作轨迹，但这些动画不会生成动作播报或聊天内容。音效均为游戏反馈音，不包含角色说话。

## 验证

### 可视化本地测试

无需修改主大厅或第三方仓库根注册表，即可启动插件自己的本地测试台。在游戏大厅仓库根目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\game-hall-third-party-games\plugin-bomb-people\tools\start_local_test.ps1
```

脚本会启动真实 Python 规则引擎和 Vue 游戏界面，并自动打开 `http://127.0.0.1:4173/`。按 `Ctrl+C` 会同时停止两项本地服务。测试台顶部提供：

- `2–8` 人房间快速重置，以及连续多局随机地图轮换；
- 当前操控玩家切换，可逐个验证不同玩家视角；
- 正式开局、暂停/继续、快速进入螺旋落石、生成当前玩家夺冠结算；
- 15 种道具的附近投放和直接授予，便于测试自动拾取、拳套、扔雷、脚踢、骷髅等能力；
- 正式 `WASD`、`Space`、`C`、`Z`、`X` 键盘操作和移动端触屏按钮。

本地测试台只替代大厅的房间外壳，地图、玩家、炸弹、爆炸、掉落、拾取、计时和结算全部调用 `backend/engine.py` 的正式实现。它不会写入账号或大厅战绩，也不会把插件注册到生产大厅。

如果端口被占用，可以指定其他端口：

```powershell
powershell -ExecutionPolicy Bypass -File .\game-hall-third-party-games\plugin-bomb-people\tools\start_local_test.ps1 -WebPort 4273 -ApiPort 10629
```

服务端诊断日志位于插件内的 `.local-test/server.error.log`，该目录已被 Git 忽略。发现 Bug 时，记录地图、人数、当前操控玩家、复现按键步骤和截图；若页面提示服务异常，再一并提供该日志，即可直接按复现步骤修改。

### 一键自动测试

运行下面的脚本会依次执行后端规则测试、正式插件与测试台类型检查、Vue 组件测试以及测试台生产构建：

```powershell
powershell -ExecutionPolicy Bypass -File .\game-hall-third-party-games\plugin-bomb-people\tools\run_local_tests.ps1
```

也可以分别运行：

在游戏大厅仓库根目录运行：

```powershell
python -m pytest game-hall-third-party-games/plugin-bomb-people/tests/test_engine.py -q
frontend\node_modules\.bin\vue-tsc.cmd -p game-hall-third-party-games/plugin-bomb-people/tsconfig.json --noEmit
```

前端组件测试文件为 `frontend/GameView.test.ts`；本地测试服务测试为 `tests/test_local_test_server.py`。正式挂载为 `game-hall-community-games/plugin-bomb-people` 后，也可使用大厅的社区插件 Vitest 命令运行。

## 发布说明

本实现没有修改第三方仓库根部的 `registry.json`，因此不会擅自出现在生产大厅。维护者审核后，可单独把 `plugin-bomb-people` 加入发布注册表；不需要修改主大厅业务代码。
